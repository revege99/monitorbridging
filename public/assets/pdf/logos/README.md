# Logo bersama PDF

`bpjs-kesehatan.png` adalah logo BPJS Kesehatan yang sama dengan referensi pengguna,
disalin dari aset Khanza lokal `anjungan/img/logobpjs.png` tanpa perubahan gambar.

Gunakan partial `pdf.partials.bpjs-logo` untuk dokumen PDF lain. Gambar disematkan
sebagai data URI sehingga cetak tidak memerlukan akses jaringan maupun URL aset.
Jangan menempatkan PDF pasien atau data medis di direktori publik ini.
